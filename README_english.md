# hybrid_pqc_pls_sim

Step-by-step simulation of a hybrid PQC–PLS key-establishment protocol
(Step 1 → Step 6, plus the data plane) over a physical channel modelled
according to 3GPP TR 38.901, together with a security evaluation (nineteen
attacks) and a performance evaluation.

Every cryptographic operation is a real implementation, not a stand-in model:

| Component | Implementation |
|---|---|
| KEM | ML-KEM-768 (FIPS 203, `kyber-py`) |
| Signature | ML-DSA-65 (FIPS 204, `dilithium-py`) |
| AEAD | AES-256-GCM (`cryptography`) |
| Hash / MAC / KDF | SHA3-256, HMAC-SHA-256, HKDF (RFC 5869) |
| Secure sketch | Binary BCH over GF(2^m), implemented here (Berlekamp–Massey + Chien search) |
| Privacy amplification | Toeplitz universal hash (strong extractor), seed derived from `T_2` |
| Min-entropy | NIST SP 800-90B style estimators (most-common-value and first-order Markov) |

## Installation and running

```bash
python3 -m venv .venv && ./.venv/bin/pip install -r requirements.txt

./.venv/bin/python experiments/run_all.py            # everything, about 2 minutes
./.venv/bin/python experiments/run_all.py --quick    # reduced run
./.venv/bin/python -m unittest discover -s tests -v  # 36 unit tests
```

Output is written to `results/`: `report.md` (the consolidated report),
`functional_trace.txt` (a step-by-step execution trace), `attacks.csv`,
`security.json`, `performance.json` and eight figures `fig_*.png`.

Individual parts:

```bash
./.venv/bin/python experiments/run_functional.py         # correctness verification
./.venv/bin/python experiments/run_security.py           # attacks and parameter sweeps
./.venv/bin/python experiments/run_performance.py        # latency, bytes, throughput
./.venv/bin/python experiments/run_all.py --report-only  # rebuild report.md from the JSON files
```

## Physical channel model

TDL-A/B/C profiles from TR 38.901. Each tap is a Rayleigh process generated by
a sum-of-sinusoids (Jakes) method, giving the temporal autocorrelation
`J_0(2π f_d Δt)` and a coherence time of `0.423/f_d`.

The channel frequency response at a subcarrier is
`H(t,f) = Σ_l a_l(t) e^{-j2π f τ_l}`.

Reciprocity and its real impairments: both directions share one propagation
realisation (TDD), but differ in (i) independent receiver noise, (ii) a static
RF calibration error, both scalar and per-subcarrier, and (iii) the delay
`tdd_gap_us` between the two soundings.

Eavesdropper: `H_E = ρ·H + sqrt(1-ρ²)·H_ind`, so `ρ → 1` models an eavesdropper
lying inside the coherence volume of the legitimate link, which is the
worst case.

## Adversary model

Dolev–Yao on the radio interface: the adversary observes, modifies, deletes and
replays every flight, and can sound the channel herself, since `sid` and `N_U`
are sent in the clear and she can therefore derive `probe_ctx`. She does not
hold the long-term ML-DSA keys. Two additional compromise experiments hand her
`K_PQC` directly (A15) or `K_PHY` directly (A16), in order to measure the
hybrid guarantee itself.

## Principal findings

1. **Both branches are correct.** A good channel gives `G_PHY = 1` and a session
   key that mixes `K_PQC` with a 128-bit `K_PHY`; a dead channel gives
   `G_PHY = 0` and the session still completes on the post-quantum baseline. The
   two endpoints never diverge, because `G_PHY` is MACed in Step 4 and rechecked
   inside the associated data of the key confirmation in Step 6.
2. **All nineteen attacks are caught** at the step the design predicts.
3. **The hybrid guarantee holds in both directions** (A15, A16).
4. **Denying the PLS component is not denial of service** (A19): jamming only
   drives `G_PHY` to 0.
5. **Entropy estimation alone is not a safety mechanism.** At −10 dB SNR the
   estimator still passes, because noise adds apparent entropy; what actually
   closes the gate is the local SNR test together with the interactive
   reconciliation check `r_U`.
6. **Sampling more finely than the coherence bandwidth lowers the extractable
   budget**: the raw bit count grows but the entropy does not, while syndrome
   leakage grows linearly.

Full numbers, tables and figures: see `results/report.md`.

## Known limitations

See Section 7 of `results/report.md`: the channel is a stochastic model rather
than a measured trace; min-entropy is estimated; the mask inside `W` is public;
`v_B` is treated as a computational commitment; power-amplifier distortion and
IQ imbalance are not modelled.
